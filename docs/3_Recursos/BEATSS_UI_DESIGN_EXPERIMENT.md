# BEATSS UI Design Experiment

Estado: experimental / no aprobado.

La interfaz de BEATSS está en una fase de exploración visual. Las propuestas pueden cambiar de forma amplia hasta que Sossa elija una dirección. Este documento evita que una versión provisional se interprete como una regla de UI definitiva.

## Criterios temporales

- Priorizar legibilidad y coherencia entre landing, editor de licencias, catálogo, dashboard, checkout y móvil.
- Evitar combinaciones heredadas de temas que produzcan texto ilegible o paneles negros inesperados.
- Mantener la lógica de negocio y los selectores funcionales mientras se experimenta con la presentación.
- No congelar colores, tipografías, espaciado o componentes como sistema oficial sin aprobación explícita.
