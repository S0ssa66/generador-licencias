# Paquete de corrección de obras registradas en BMI

## Propósito

Este paquete sirve para solicitar a BMI la actualización de información de
obras que ya aparecen registradas en su catálogo. No es un nuevo registro de
obra. El split sheet de las obras todavía no ha sido proporcionado y no se
asume ningún acuerdo, porcentaje ni participante.

## Archivos del paquete

1. `01_BMI_Work_Update_Request_EN.md` — solicitud formal dirigida a BMI.
2. `02_BMI_Letter_of_Direction_EN.md` — carta de instrucciones para que la
   firmen las partes afectadas.
3. `03_BMI_Correction_Matrix.csv` — matriz de datos actuales y correctos por
   obra.
4. `04_BMI_Email_Draft_EN.md` — correo listo para completar y enviar.
5. `05_BMI_Submission_Checklist.md` — control final de anexos y envío.

## Qué falta completar antes del envío

- Título de cada obra.
- Número de obra BMI.
- Número de cuenta BMI.
- Datos actualmente publicados en BMI.
- Datos corregidos.
- Nombre legal, nombre mostrado, PRO e IPI/CAE de cada participante.
- Editorial/publisher y participación editorial, si existe.
- Motivo concreto de cada corrección.
- Split sheet firmado, cuando corresponda y cuando sea proporcionado.
- Firma de todas las personas cuya participación se reduzca, se elimine o se
  modifique.

## Anexos

Cuando se proporcione el split sheet firmado, debe adjuntarse como respaldo.
Si contiene porcentajes de máster y publishing, la matriz debe repetir
únicamente los datos de composición/publishing que BMI necesita.

## Regla de porcentajes BMI

BMI trabaja con una escala de 200%: 100% para las participaciones de
writer/composer y 100% para las participaciones de publisher. No mezclar el
porcentaje del máster con el porcentaje de composición/publishing.
