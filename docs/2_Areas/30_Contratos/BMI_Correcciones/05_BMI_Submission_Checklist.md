# Checklist de envío a BMI

## Antes de preparar el correo

- [ ] Confirmar que cada obra ya aparece en BMI Online Services o Songview.
- [ ] Obtener el número de obra BMI de cada canción.
- [ ] Confirmar el número de cuenta BMI del solicitante.
- [ ] Guardar una copia de la información actual de BMI para comparar.
- [ ] No crear un registro nuevo de la obra.

## Por cada obra

- [ ] Título actual y título correcto.
- [ ] Título alternativo actual y correcto, si existe.
- [ ] Todos los escritores/compositores y sus shares actuales/correctos.
- [ ] Todos los publishers y sus shares actuales/correctos.
- [ ] IPI/CAE y PRO de cada participante.
- [ ] Información del artista intérprete, si debe corregirse.
- [ ] Motivo de la corrección.
- [ ] Split sheet firmado, cuando sea proporcionado.
- [ ] Carta de instrucciones firmada por las partes afectadas.
- [ ] Documento adicional si se elimina o reduce la participación de alguien.

## Si se corrige el nombre de un participante

- [ ] Indicar nombre actual y nombre que debe aparecer en BMI.
- [ ] Confirmar que el nombre correcto ya está conectado a la cuenta BMI
      correspondiente.
- [ ] Adjuntar documento que respalde la forma correcta del nombre, si BMI lo
      solicita o si se trata de un cambio legal.

## Si se corrige una editorial o administración

- [ ] Adjuntar acuerdo de administración o subedición firmado.
- [ ] Adjuntar carta de instrucciones firmada por las partes.
- [ ] Para una terminación, indicar la fecha efectiva.
- [ ] Indicar qué obras se mantienen y cómo se cobrarán fondos posteriores,
      si aplica.

## Control de porcentajes

- [ ] Los porcentajes de writer/composer están separados de los de publisher.
- [ ] La suma de writer shares es correcta según la estructura de la obra.
- [ ] La suma de publisher shares es correcta si existe publisher.
- [ ] Los porcentajes del máster no fueron copiados por error en la matriz BMI.

## Envío

- [ ] Adjuntar únicamente documentos finales, legibles y firmados.
- [ ] No incluir contraseñas, tokens, claves bancarias ni archivos `.env`.
- [ ] Enviar a `reviseworks@bmi.com`.
- [ ] Guardar una copia exacta del correo y sus anexos.
- [ ] Solicitar confirmación de recepción.
- [ ] No declarar que BMI corrigió las obras hasta verificar el catálogo o
      recibir confirmación escrita.
